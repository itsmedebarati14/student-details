THE INTERNSHIP PROJECT

About This Project

This website demonstrates the AWS Cloud Internship beginner task: deploy a static frontend on Amazon S3 and connect a feedback form to a serverless backend using AWS Lambda.

  • Static website hosting with Amazon S3
  • Contact form with input validation
  • Serverless processing using AWS Lambda
  • HTTPS endpoint using API Gateway
  • Low-traffic and cost-conscious deployment
